# Changelog

## 2.0

### New

- Luminous Calm visual system with adaptive ambient backgrounds
- Today dashboard with animated progress and overdue tasks
- Two-week planning experience
- Unified Library with search, spaces, lists, inbox, and completion history
- Task notes, effort estimates, completion timestamps, and subtasks
- Redesigned quick capture and task detail experiences
- Home Screen widget for daily progress and the next task
- App Shortcuts for capture and navigation
- Redesigned onboarding, settings, and What's New presentation

### Improved

- Reduced navigation from six tabs to three clear destinations
- Notification permission is requested contextually instead of at first launch
- Full SwiftData model graph is registered at the root
- Additive model changes preserve existing task data through lightweight migration
- Recurring tasks carry notes and estimates into their next occurrence
- Dark mode, Dynamic Type, haptics, and accessibility labeling

### Compatibility

- iOS 17+
- Swift 6
- Aura and AuraWidget use the `group.com.kiran.Aura` App Group
